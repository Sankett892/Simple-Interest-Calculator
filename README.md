# Simple Interest Calculator

A beginner-friendly calculator that computes simple interest and the total amount payable using the principal amount, annual interest rate, and time period.

## Overview

Simple interest is calculated only on the original principal amount. This project helps users quickly calculate the interest earned or paid over a specified period.

## Formula

**Simple Interest (SI) = (P × R × T) / 100**

Where:

- `P` = Principal amount
- `R` = Annual rate of interest (in percent)
- `T` = Time period (in years)

**Total Amount = Principal + Simple Interest**

## Example

Suppose:

- Principal = ₹10,000
- Annual interest rate = 5%
- Time = 2 years

Calculation:

- Simple Interest = (10,000 × 5 × 2) / 100 = ₹1,000
- Total Amount = 10,000 + 1,000 = ₹11,000

## Features

- Accepts principal amount, annual interest rate, and time period.
- Calculates simple interest using the standard formula.
- Displays the total amount (principal + interest).
- Includes a worked example for easy understanding.

## Input

1. Principal amount
2. Annual interest rate (percentage)
3. Time period (years)

## Output

- Simple interest
- Total amount

## Technologies

This is a basic programming exercise. It can be implemented using Python, Java, C++, or JavaScript.

## How to Use

1. Enter the principal amount.
2. Enter the annual interest rate.
3. Enter the time period in years.
4. Calculate the simple interest using the formula above.
5. Add the interest to the principal to obtain the total amount.

## Validation

The principal amount and time period should be non-negative. The interest rate should also be non-negative. Ensure all inputs are valid numbers before performing the calculation.

## Project Purpose

This project demonstrates basic arithmetic operations, user input, formula implementation, and displaying calculated results. It is suitable as a beginner-level programming project.
